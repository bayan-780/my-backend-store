
# مشروع المتجر الإلكتروني - الخادم (Backend API.

هذا المشروع هو واجهة برمجة التطبيقات (API) لمتجر إلكتروني، تم بناؤه باستخدام Node.js و Express وقاعدة بيانات PostgreSQL.

## طريقة التشغيل
1. تثبيت الحزم: `npm install`
2. إنشاء ملف `.env` ووضع بيانات قاعدة البيانات.
3. تشغيل الخادم: `npm run dev`

## مسارات الـ API (API Endpoints) - حسب الخطة المعتمدة

### المرحلة الثالثة: المصادقة والصلاحيات (Auth)
- `POST /api/v1/auth/register` : إنشاء حساب جديد.
- `POST /api/v1/auth/login` : تسجيل الدخول.

### المرحلة الرابعة: المتاجر والمنتجات (Stores & Products)
- `GET /api/v1/stores` : جلب المتاجر النشطة.
- `POST /api/v1/stores` : إنشاء متجر جديد (pending).
- `GET /api/v1/products` : جلب المنتجات.
- `POST /api/v1/stores/:storeId/products` : إضافة منتج.
- `PATCH /api/v1/products/:id` : تعديل منتج.
- `DELETE /api/v1/products/:id` : حذف منتج.

### المرحلة الخامسة: الطلبات (Orders)
- `POST /api/v1/orders` : إنشاء طلب جديد (مع خصم المخزون وحساب الإجمالي).

### المرحلة السادسة: مسارات المدير (Admin)
- `GET /api/v1/admin/stores` : جلب جميع المتاجر.

- `PATCH /api/v1/stores/:id/status` : تغيير حالة المتجر.
- `GET /api/v1/admin/users` : جلب المستخدمين.
- `GET /api/v1/admin/orders` : جلب الطلبات.



> **ملاحظة تقنية هامة:** تم تصميم قاعدة البيانات باستخدام **PostgreSQL** بدلاً من Oracle، نظراً لأن إصدار Oracle المتاح (10g) قديم جداً وتوقف دعمه رسمياً، مما يسبب مشاكل تقنية لا حصر لها مع أنظمة التشغيل الحديثة. تم الحفاظ على نفس هيكل الجداول والعلاقات (ERD) المطلوب حرفياً لضمان توافق الواجهة.
